
# 🛍️ Product Search & Filter App  
A fast and interactive product filtering system built with JavaScript, designed to simulate a real online store experience.

# 🔗 Live Demo  
👉 https://zohrehchenari1995.github.io/FilterAndSearchJs/data/items.json


## 🚀 Overview  
This project allows users to **search products by name** and instantly see filtered results.  
Additionally, clicking on any **product category menu** displays all items related to that category.

This app demonstrates my skills in **JavaScript**, **DOM manipulation**, **UI/UX logic**, and **data-driven rendering**.

## ✨ Features  
- 🔍 Real-time search filtering  
- 🗂️ Category-based filtering  
- ⚡ Fast, lightweight, and fully dynamic  
- 📱 Responsive design  
- 🧠 Smart matching logic (case-insensitive)

## 🛠️ Tech Stack  
- HTML5  
- CSS3  
- JavaScript (ES6+)
